🔖 ติดตั้ง Bookmarklet
1
คัดลอกโค้ด Bookmarklet
กดปุ่ม "คัดลอก" ด้านล่าง
2
สร้าง Bookmark ใน Safari
กด Share (□↑) → Add Bookmark → บันทึกชื่อ "Subtitle TTS"
3
แก้ไข URL ของ Bookmark
Bookmarks → Edit → ลบ URL เดิม → วางโค้ดที่คัดลอก
4
ใช้งาน
เปิดวิดีโอ → กด Bookmark → Panel เด้งขึ้นมา → กด "เริ่ม TTS"
📋 โค้ด Bookmarklet
⚡ Apple Shortcuts (แนะนำ)

Apple Shortcuts สามารถรัน JavaScript บนหน้า Safari ได้โดยตรง ผ่าน Share Sheet — ทำงานเหมือน Extension มากที่สุด

1
เปิด Shortcuts App บน iPhone
หา App "Shortcuts" (รูปกรรไกรสีน้ำเงิน)
2
กด + เพื่อสร้าง Shortcut ใหม่
กด "Add Action" → ค้นหา Run JavaScript on Web Page
3
วางโค้ดลงใน Action
กด "คัดลอกโค้ด Shortcut" ด้านล่าง แล้ววางในช่อง Script
4
เพิ่มใน Share Sheet
Shortcut Settings → Use as Quick Action → Share Sheet ✅
5
ใช้งาน
เปิดวิดีโอ → กด Share (□↑) → เลือก "Subtitle TTS" → อ่านออกเสียงทันที
📋 โค้ด Shortcut Script

💡 วิธีใช้บน YouTube
1
เปิดวิดีโอ YouTube ใน Safari
เล่นวิดีโอที่มีคำบรรยาย (CC)
2
เปิด Subtitle ใน YouTube ก่อน
กด CC ในตัวเล่น → เลือกภาษาที่ต้องการ
3
รัน Shortcut หรือ Bookmarklet
กด Share → Subtitle TTS หรือกด Bookmark
4
กด "เริ่ม TTS" แล้วฟัง
ระบบจะอ่านออกเสียงตาม Subtitle ที่แสดงอยู่
